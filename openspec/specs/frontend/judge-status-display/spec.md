# frontend/judge-status-display Specification

## Purpose
让提交记录页的判题状态文案与后端枚举语义一致：状态 2 只表示"判题流程完成"（不论判题对错），不得显示为"通过"，避免答错的提交被绿色"通过"文案误导用户。

## Requirements

### Requirement: 判题状态文案语义一致

提交记录列表的状态文案必须与后端判题状态枚举语义一一对应：0-等待中、1-判题中、2-判题完成、3-失败。状态 2 不得展示为"通过"。

#### Scenario: 判题完成（未通过）的展示
- **WHEN** 某提交判题流程结束（status=2）且判题结果为答案错误
- **THEN** 该提交的状态列显示"判题完成"，而非"通过"

#### Scenario: 判题失败的展示
- **WHEN** 某提交判题过程异常（status=3）
- **THEN** 该提交的状态列显示"失败"
